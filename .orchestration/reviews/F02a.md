## Method (part A)

1. **Order of work.** I read `03_AGENT_PROMPTS.md` (the shared contract and the A6 role), D-072, `workshop-math.md`, `workshop-inputs.md`, `workshop-clip-rules.md`, the schema structure and the fixtures. I did **not** open `compute_f02a_fixtures.py` or `mutation_check.py`, and I still have not opened them. I read the builder's logs only after my own model had reproduced every fixture.
2. **A new model, `intmodel.py`.** It differs by construction from the builder's `fractions.Fraction` reference and from the attempt-3 A6 BigInt-rational JavaScript model:
   - Every nominal flow of year t is one Python `int` N, meaning N / 10000^t.
     - D_t = a·(10000+i)^t.
     - P_j,t = a_j·pre·(10000+q_j)^{t−s_j}.
     - pre = 10000^{s_j}, or (10000+i)^{s_j} for today dollars.
   - Values are rounded half-even to whole cents with integer `divmod`.
   - Today-dollar values are N / (10000+i)^t, rounded the same way.
   - Exact strings come from scaled-integer formatting.
   - C_R is a single integer fraction reduced with `math.gcd`: 10000·Σ_k G_{t_R+k}(10000+r)^{H−1−k} / (10000^{t_R}(10000+r)^H).
3. **Faulty runtimes.** Each is a switch inside the same model; the empty switch set is the contract reading.
   - `today_dollars_uses_q`: pre = (10000+q_j)^{s_j}.
   - `joint_uses_partner`: A_o = the partner's age for `joint` sources.
   - Further variants, including the P3-1 rounding faults and the readings that WM37 and WM38 claim to catch.
4. **A third path.** `hand_checks.py` recomputes the closed forms with `decimal.Decimal` at 60 digits.
5. **Inputs.** Every fixture input and clip input is checked with jsonschema 4.26 (draft 2020-12), and with my own XF-04 to XF-06 checker.
